# Bakterien-Jump

Ein handgezeichnetes Bio-Tech-Browser-Spiel auf technischem Rasterpapier:
Rette das kawaii Bakterium Bacti vor großen und kleinen Laborgegenständen.

Steuerung:

- Springen und Doppelsprung: Leertaste, Pfeil nach oben, Klick oder Tippen
- Bücken: Pfeil nach unten oder die Bücken-Taste gedrückt halten
